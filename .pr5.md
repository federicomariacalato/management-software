## Problem

`percentChange` returned `0` when the previous period had no baseline:

```ts
function percentChange(current: number, previous: number): number {
  if (previous === 0) return 0;
  ...
}
```

Relative change from zero is **undefined**, not zero. Because `KpiCard` derives its colour from `change >= 0`, this rendered a **green `+0%` badge**, which reads as "no change". Reproduced:

| Previous | Current | Rendered | Reality |
|---|---|---|---|
| EUR 0 | EUR 500 | `+0%` | growth from an empty period, not expressible as % |
| 0 orders | 1 order | `+0%` | "no change" |
| undefined AOV | EUR 100 | `+0%` | new metric, not flat |

A second problem compounded it: with no orders in the rolling 30-day window the dashboard rendered four confident zeros — `0,00 €`, `0`, `+0%`, and a flat sparkline — with **no error and no empty state**. It looked like a working analytics page reporting a collapse, when in fact there was simply nothing in the period.

## Fix

- `percentChange` moved to `utils/percentChange.ts` and now returns `number | null`. `null` means "no baseline".
- `KpiData.change` is now `number | null`. This is a **breaking type change on purpose**: the compiler forces every consumer to handle the undefined-baseline case instead of silently rendering a number.
- `KpiCard` renders a neutral `no data` badge and a grey trend line when `change` is `null`, so "no baseline" is visually distinct from "flat".
- `getKpiData` now returns `KpiResult` (`{ kpis, hasSalesInPeriod }`). `KpiSection` renders an explicit empty state pointing at `/orders`.

The empty-state flag is computed in the derivation layer rather than inferred in the component. Inferring it in the UI would have meant string-matching a formatted currency (`value !== "0,00 €"`), which breaks the moment the locale or currency changes.

## Impact

- Growth from an empty period now shows `no data` instead of a misleading green `+0%`.
- An empty 30-day window shows a clear message instead of four zeros.
- The KPI service contract now states emptiness explicitly rather than leaving the UI to guess.

## Risk

Low. The type change is contained to the KPI layer — `tsc -b` verifies every consumer was updated and `vite build` passes. `eslint` is clean on all touched files.

Not covered here: the mock data itself decays to zero 30 days from now, which makes this empty state show up on `main` shortly. Tracked separately as it needs a decision about how the demo dataset should be generated.
